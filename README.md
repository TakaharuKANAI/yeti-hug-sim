# YETI 体験フローシミュレータ

毛むくじゃらの生きものを撫でたり抱きしめたりすると、腕・お腹（呼吸）・背筋が反応する——
その体験を、実機を組む前にブラウザで確かめるためのシミュレータです。

**→ [ブラウザで試す](https://takaharukanai.github.io/yeti-hug-sim/)**

M5Stack Core2 で動かしているファームウェアの「生きものモード」と同じ計算をそのまま
JavaScript に移してあります。ここで決めたパラメータは、そのままスケッチに持っていけます。

## 入力

| 操作 | 内容 |
|---|---|
| ドラッグ / ← → | 人の手を近づける・離す（ToF 距離センサ: 6〜70cm） |
| A S D F G | 背中のタッチセンサ 1〜5（手が近いときだけ反応する） |

## ジェスチャ

| ジェスチャ | 条件 |
|---|---|
| 順なで | タッチ 1→5 の向きに順に |
| 逆なで | 5→1 の向きに、3段以上 |
| びっくり | 同じところを素早く2回以上 |
| すごくびっくり | 3つ以上を同時に、素早く3回以上 |
| だきしめる | 2つ以上を長押し |
| はっけん / こどく | そばに人がいるか、いないか |

## 出力（サーボ4軸）

| 軸 | 動き |
|---|---|
| 右腕 / 左腕 | 付け根を軸に開閉。だっこで前に閉じて抱き返す。びっくりで上にあがる |
| おなか | パンタグラフで前にふくらむ＝呼吸 |
| 背すじ | パンタグラフで伸び縮み。元気だと伸び、眠いと縮む |

## きもち

両極の3軸で持っています。時間とともに減衰し、放っておくと眠くなります。

- こどく ↔ はっけん
- けいかい ↔ あんしん
- ねむけ ↔ わくわく

## 実機のタッチをつなぐ（BLE）

M5Stack CoreS3 に `M5CoreS3_TouchAreas` を書き込むと、背中（Port B）とお腹（Port A）の MPR121 の状態を
BLE（名前 `YETI-Touch`）で 1秒に50回送ります。ページ上部の「M5 につなぐ」から Chrome / Edge でつなぎます
（Safari は Web Bluetooth 非対応。https か localhost で開く必要があります）。

画面は左上に背中、左下にお腹、右に YETI のアニメーション。エリアごとに次の5つを検知して光らせます。

| パターン | 判定 | 背中の反応 | お腹の反応（仮） |
|---|---|---|---|
| ぎゅっ | 手のひら、または3本以上に触れたまま 0.5 秒 | だきしめる | だきしめる |
| なでる ↓ | M5 の判定（下へ） | 順なで | おなか なでなで |
| なでる ↑ | M5 の判定（上へ） | 逆なで | おなか なでなで |
| ポンポン | いったん指が離れる軽いタップが 0.7 秒以内に2回（位置は問わない。PC 側で判定） | びっくり | ぽんぽん |
| くすぐり | ざわざわ：指先を毛の中でもぞもぞ動かし続ける（強弱の揺れが 0.5 秒続く）。連打・往復にも切り替え可 | くすぐったい | くすぐったい |

判定の値は画面下の「検知の調整」で変えられます。つないでいないときは、キーボード（A〜G）の操作が背中のパネルに出ます。

ローカルで開くとき: `python3 -m http.server 8765` → http://localhost:8765

## 実機側

M5Stack Core2 + サーボ4個（ワイヤー駆動の腕 2 + パンタグラフ 2）、静電容量タッチ、ToF 距離センサ。
ファームウェアは別リポジトリにあります。
