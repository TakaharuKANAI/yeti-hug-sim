# YETI 体験フローシミュレータ

毛むくじゃらの生きものを撫でたり抱きしめたりすると、腕・お腹（呼吸）・背筋が反応する——
その体験を、実機を組む前にブラウザで確かめるためのシミュレータです。

**→ [ブラウザで試す](https://takaharukanai.github.io/yeti-hug-sim/)**

M5Stack Core2 で動かしているファームウェアの「生きものモード」と同じ計算をそのまま
JavaScript に移してあります。ここで決めたパラメータは、そのままスケッチに持っていけます。

## 入力

| 操作 | 内容 |
|---|---|
| ドラッグ / ← → | 人の手を近づける・離す（ToF 距離センサ: 6〜70cm） |
| A S D F G | 背中のタッチセンサ 1〜5（手が近いときだけ反応する） |

## ジェスチャ

| ジェスチャ | 条件 |
|---|---|
| 順なで | タッチ 1→5 の向きに順に |
| 逆なで | 5→1 の向きに、3段以上 |
| びっくり | 同じところを素早く2回以上 |
| すごくびっくり | 3つ以上を同時に、素早く3回以上 |
| だきしめる | 2つ以上を長押し |
| はっけん / こどく | そばに人がいるか、いないか |

## 出力（サーボ4軸）

| 軸 | 動き |
|---|---|
| 右腕 / 左腕 | 付け根を軸に開閉。だっこで前に閉じて抱き返す。びっくりで上にあがる |
| おなか | パンタグラフで前にふくらむ＝呼吸 |
| 背すじ | パンタグラフで伸び縮み。元気だと伸び、眠いと縮む |

## きもち

両極の3軸で持っています。時間とともに減衰し、放っておくと眠くなります。

- こどく ↔ はっけん
- けいかい ↔ あんしん
- ねむけ ↔ わくわく

## 実機をつなぐ（BLE）

M5Stack CoreS3 に `M5CoreS3_YetiMain` を書き込むと、タッチ4エリアとからだの状態を
BLE（名前 `YETI-Touch`）で送ります。ページ上部の「M5 につなぐ」から Chrome / Edge でつなぎます
（Safari は Web Bluetooth 非対応。https か localhost で開く必要があります）。

- タッチ（1秒に50回）：背中・お腹・右腕・左腕の電極の強さ、位置、動き
- からだ（1秒に10回）：M5 のモード、サーボ6軸、空気圧、距離、きもち、ジェスチャ

「M5 の姿勢をそのまま映す」がオンのとき、右の YETI は M5 のサーボの値で動きます（ミラー）。
オフにすると、PC のシミュレータが実機のタッチから姿勢を作ります。
旧版の `M5CoreS3_TouchAreas` でもつながります（背中・お腹だけ表示）。

画面は左上に背中、右上に右腕、左下にお腹、右下に左腕、右に YETI のアニメーション。
エリアごとに次の4つを検知して光らせます。

| パターン | 判定 | 背中 | お腹（仮） | 腕（仮） |
|---|---|---|---|---|
| ぎゅっ | 手のひら、または3本以上に触れたまま 0.5 秒 | だきしめる | だきしめる | だきしめる |
| なでる ↓ | M5 の判定（下へ／先へ） | 順なで | おなか なでなで | その腕が揺れる |
| なでる ↑ | M5 の判定（上へ／付け根へ） | 逆なで | おなか なでなで | その腕が揺れる |
| ポンポン | トン（触れてから 1 秒以内に離れる）が2回（離してから次に触れるまで 1 秒以内）。指先の軽いトンから手のひらのポンまで、位置は問わない | びっくり | ぽんぽん | その腕が上がる |

判定の値は画面下の「検知の調整」で変えられます。つないでいないときは、キーボード（A〜G）の操作が背中のパネルに出ます。

ローカルで開くとき: `python3 -m http.server 8765` → http://localhost:8765

## 実機側

M5Stack CoreS3 + ベース。配線の全体は `fablication_advanced/M5CoreS3_YetiMain/SYSTEM.md`。

| 端子 | つなぐもの | アドレス |
|---|---|---|
| Port A（G2/G1） | お腹 → 左腕 → 背中 → 右腕（MPR121） | 0x5A / 0x5B / 0x5C / 0x5D |
| Port B（G9） | 目の LED（8x8 WS2812B ×2、中央 4x4） | — |
| Port C（G18/G17） | ハブ → 8Servos・ToF・DAC2 | 0x25 / 0x29 / 0x59 |
